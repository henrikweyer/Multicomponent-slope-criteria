# Multicomponent-slope-criteria

This repository contains the simulation code for the project

**Classification of Intracellular Protein Patterns from Reactive Equilibria**

by Henrik Weyer*, Ching Yee Leung*, and Erwin Frey. (* equal contribution)

The code is associated with the corresponding figures:

_multi-component_Classification_MIN.nb_ &mdash; Application of the slope criteria to the skeleton model for the _E. coli_ Min protein system; Fig. 9

_multi-component_classification_PAR.nb_ &mdash; Application of the slope criteria to the _C. elegans_ PAR protein system; Fig. 10 (also used for Fig.11)

_Multi-component_classification_PAR.ipynb_ &mdash; Determining lateral instability in the PAR protein system from density titration; Fig. 11

## Mathematica notebooks
The Mathematica notebooks are written for Mathematica version 13.0.

## iPython notebook
The notebooks are written for Python 3.11 using jupyter-notebook.
